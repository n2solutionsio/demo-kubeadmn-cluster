[`n2solutions.kubeadm`](https://github.com/n2solutionsio/ansible-collection-kubeadm)

assistance (**AI-authored**). It is disclosed here because `docs/build-cluster.md`

Kubernetes packages. It does not install Kubernetes or create a cluster — both are
done manually, per the runbook.
